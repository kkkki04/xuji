分享到微信

将把选中（或当前显示）的图片整理成可分享的内容。

苹果手机（iPhone / iPad）
  1. 点「导出 PDF」，在微信里发这个 PDF 文件
  2. 对方直接点开就能看：图片、名称、备注都在，一页一张，可缩放
  3. PDF 在「文件」「备忘录」「微信」里都能正常预览，不依赖浏览器
电脑 / 安卓：分享网页（图片可点击）
  1. 点「导出分享网页」，得到 .html 文件
  2. 对方用 Chrome / Edge / Safari 打开：点图放大，可复制、保存
  3. 注意：iPhone 的「文件」预览和「备忘录」不执行脚本，用这种方式看不到内容
直接粘贴到聊天
  1. 点「复制图文长图」，到微信窗口 Ctrl + V
PDF 和分享网页都是单个文件，图片已内嵌，离线可用。

数据备份

把全部文件夹、分组、图片、Markdown 文档和备注导出成一个文件。新版使用流式 .jsonl 备份，图片很多也不会白屏；导入时仍会把内容追加到现有数据，不会覆盖已有文件夹和内容。

怎么换设备
  1. 在这台电脑点「导出全部数据（.jsonl 推荐）」，会下载一个 序集备份_日期.jsonl
  2. 文件很大时，先把它压缩成 .zip 再发；微信里请按「文件」发送，不要按图片发送
  3. 在新电脑打开序集，点「备份」→「导入备份（追加）」，选 .jsonl（压缩过就先解压）
  4. 导入会把备份里的文件夹、分组、图片和文档追加到当前数据中，不会覆盖现有内容；同名文件夹会自动加「导入」后缀
备份包含图片原图、Markdown 文档内容、名称、备注、完成状态、分组、文件夹层级和收藏。导出或导入过程中请不要关闭序集；图片很多时慢一些属正常现象。
