# 序集 XUJI · 图片与文档整理

> 让每一份灵感，都有序可循。
>
> 2026-11 品牌升级：原「图记 / TuJi」更名为「序集 / XUJI」。数据目录、IndexedDB、WebView2 / Electron 数据路径和 `tuji.local` 协议保持原样，升级后继续读取原有数据。

一个离线的图片 + 备注管理小工具：**复制粘贴图片 → 命名 → 写备注 → 一键复制分享到微信**。

整个软件只有一个 `index.html` 文件，不需要安装、不需要联网、不需要登录，图片和备注只保存在你自己的浏览器里。

## 文档（2026-11-03 更新）

- 支持导入 **Markdown 文档**：点顶部「添加」→「添加 Markdown 文档」选择 `.md` 文件，或直接把 `.md` 拖进窗口 / 文件夹；也可以「新建 Markdown 文档」从零写。
- 文档卡片和图片卡片外观一致，缩略图位置显示文档标题和开头几行内容；文档里有图片时，缩略图直接显示那张图。
- **点击文档卡片**，右侧会滑出阅读栏，按 Markdown 渲染标题、列表、表格、引用、代码块（带复制按钮）等。
- 阅读栏左上角的 **配图缩略图**：点击可以给文档配一张图（支持拖入、`Ctrl+V` 粘贴或选文件），有图时显示大图并可一键删除；配图会作为文档卡片的缩略图。
- 阅读栏右上角的 **「编辑」** 可以改 Markdown 原文，点「保存」生效；编辑时可以「插入图片」把图片放进正文（图片随文档保存，不依赖外部文件）。
- 右侧栏可以直接「复制」原文或「下载」`.md` 文件。
- 顶部统计栏新增 **图片 / 文档 勾选筛选**：只勾图片就只看图片，只勾文档就只看文档，选择会记住。
- 文档同样支持命名、备注、收藏、完成、移动、删除和撤销。
- 备份会一起导出文档内容；ZIP 里文档在 `文档/` 目录，图片在 `图片/` 目录。
- 注意：含文档的备份需要 2026-11-03 或更新的版本才能正确导入。

## Windows 桌面版（推荐）

双击 **`序集.exe`** 直接打开原生窗口（内置 WebView2，不是浏览器套壳）。

- **单文件 exe**（约 1 MB），免安装，不创建桌面快捷方式
- 首次运行会在 exe 同级自动生成 `图记数据\` 文件夹，存放页面和你的图片数据
- 想整体搬家：把 `序集.exe` + `图记数据\` 一起拷走即可（便携）
- 运行要求：Windows 10/11，装了 Edge 即可（WebView2 运行时随之自带）
- 重复双击只会提示“已经在运行”，不会开两个实例

当前 `序集.exe` 已内置带「编辑 / 裁剪」的页面。exe 每次启动会把内置页面写到 `图记数据\web\index.html`（内容不同时才覆盖），所以：

- 不要把这个文件设为只读，否则启动会报“访问被拒绝”；
- 如果修改了 `picnote\index.html`，需要运行 `picnote\src\build.ps1` 重新编译 exe，只改网页版不会自动更新 exe。

网页版（`index.html`）仍然保留，功能和 exe 完全相同。

## 快速开始

1. 双击 **`启动.bat`**（或直接双击 `index.html`，用 Chrome / Edge 打开）
2. 启动后是**文件夹列表**，像电脑的文件管理器一样：**双击文件夹进入**；进入后左上角的 **‹ 后退 / › 前进** 可以来回切换，点面包屑「首页」也能返回
3. 文件夹可以**内嵌子文件夹**：根目录或文件夹内的**页面空白处（包括下方空白区）右键 →「新建文件夹」**，像文件管理器一样一层层往下放
4. 文件夹卡片右上角的 **☆** 可以收藏；根目录顶部可以切到 **★ 收藏** 只看收藏夹（收藏不会置顶）；点「⋯」可以打开、移动、重命名或删除
5. 进入文件夹后，底部是**分组标签栏**（二级目录）：点 `＋` 新建分组，双击标签改名，按住标签左右拖动可以排序
6. 按 **Ctrl + V** 粘贴截图，或把图片 / 整个文件夹从资源管理器或微信直接拖进窗口；图片会进入当前分组。在根目录可以把图片拖到某个文件夹卡片上，也可以直接拖到空白处（放到上次使用的文件夹）；图片是复制进序集，原文件不会被移动
7. 点名称输入框改名、点备注框写说明
8. 这个 UI 做完后，点图片**左上角的圆圈**打勾（再点取消）
9. 需要批量导出时点顶部 **管理** → 在文件夹内点图片选中，或在根目录直接点文件夹卡片选中（文件夹会包含里面的子文件夹）→ 用工具栏的复制/保存/分享/导出 ZIP 按钮；也可以点底部 **移动到文件夹** 把选中的图片移到其他文件夹（含子文件夹）；点 **完成** 退出
10. 点 **分享到微信 → 📄 导出 PDF**（发给苹果手机）或 **🔗 导出分享网页**（电脑上点开图片），也可以 **复制图文长图** 直接粘贴
11. 换电脑时点顶部 **备份 → 导出全部数据（.jsonl 推荐）**，到新电脑再 **备份 → 导入备份（追加）**；备份内容会追加到现有数据，不会覆盖已有文件夹和图片

> 建议使用 **Chrome 或 Edge**。Firefox 对“复制图片到剪贴板”的支持不完整。

## 文件夹 + 分组 + 打勾：管理 UI 进度

适合存 GPT 生成的 UI 图：**一个项目一个文件夹，一个模块一个分组，做完一张打一个勾**。

- **文件夹（可内嵌）**：启动后是文件夹列表，**双击文件夹进入**；单击只选中。进入文件夹后，子文件夹卡片直接显示在上方，没有单独的分栏标题。卡片右上角「⋯」或右键可以打开、移动到其他文件夹、重命名、删除（有子文件夹或图片时要先处理）
- **收藏文件夹**：点卡片右上角的 ☆，或进入文件夹后点路径旁的 ☆；根目录顶部切「★ 收藏」可只看收藏，收藏不会置顶，顺序仍按创建时间
- **移动文件夹**：点卡片右上角「⋯」→「移动到…」，通过面包屑和「进入」逐级浏览目标位置，点「移动到这里」确认；整个文件夹会连子文件夹、分组、图片一起移动，不能移到自身或自己的子文件夹里
- **前进 / 后退**：路径左侧的 `‹` `›` 在浏览过的文件夹之间切换；面包屑显示「首页 › 父文件夹 › 子文件夹」，点任意一级即可跳转
- **新建文件夹**：在根目录或文件夹内的页面空白处（包括下方空白区）右键 →「新建文件夹」；在文件夹内新建时会自动放在当前文件夹下面
- **新建分组**：进入目标文件夹后，点分组栏最右边的 `＋`，输入名字回车即可（Esc 取消）
- **切换分组**：点底部标签，每个标签上的 `2/5` 表示「已完成 2 张 / 共 5 张」
- **调整顺序**：按住分组标签左右拖动，会出现一条竖线提示插入位置，松手即可；顺序会自动保存
- **改名**：双击标签
- **删除分组**：右键标签 → 删除分组（分组里还有图片时会提示，需要先移走或删掉）
- **添加图片**：必须先进入一个文件夹；在文件夹列表里点「添加图片」会提示先进入文件夹
- **移动图片到其他文件夹**：右键图片 →「移动到文件夹…」，会先显示当前层文件夹，点文件夹逐级进入，最后点「移动到这里」确认；图片会进入目标文件夹当前的分组。也可以在「管理」模式勾选多张，点操作行里的「移动到文件夹」批量移动
- **移动到分组**：右键图片 →「移动到分组…」；或在「管理」模式勾选图片 → 操作行里的「移动到分组」→ 选当前文件夹里的目标分组
- **收藏图片**：点卡片右下角的 ☆（变金色 ★），收藏的图默认排在最前面；也可以在预览大图里点名称旁的 ☆，或右键图片 →「收藏这张图」
- **打勾**：点图片左上角的圆圈；也可以在预览大图里点「标记完成」，或在管理模式下多选后批量「标记完成」
- **选中图片**：先点顶部「管理」，再点图片本身（青色描边 + `✓ 已选` 标签表示已选中）；管理模式下右键图片 →「预览」看大图
- **看进度**：打勾后的卡片会变暗 + 绿框 + 绿底 `✓ 已完成`，和没做的形成明显对比；顶部还能切「未完成 / 已完成」
- **视图大小**：进入文件夹后，顶部「视图」可选紧凑 / 标准 / 宽松，图片多时用紧凑，想看清细节用宽松

再次打开会回到文件夹列表；每个文件夹上次所在的分组、分组顺序、文件夹收藏和打勾状态都会自动保存。

导出（长图 / 分享网页 / PDF / ZIP）默认只处理**当前分组**里选中的图片（在管理模式里选；没选就是当前显示的全部）。在根目录进入「管理」后选择文件夹，导出范围会变成该文件夹及其子文件夹里的全部图片，文件名和页脚会带上文件夹名，例如 `序集_登录模块_20261021.pdf`。

## 怎么分享到微信

### 方式一：PDF（发给苹果手机最稳）

1. 点顶部 **分享到微信 → 📄 导出 PDF**
2. 得到一个 `序集_登录模块_20261021.pdf`（每张图一页，名称、备注、日期都印在页面上）

## 备份 / 换电脑（推荐）

顶部 **「备份」** 是整库备份，和分享用的 PDF / ZIP 不一样：

1. 旧电脑：点 **备份 → ⬇ 导出全部数据（.jsonl 推荐）**，得到一个 `序集备份_日期.jsonl`
2. 把文件发到新电脑（微信 / U 盘 / 网盘都行）；文件很大时先压缩成 `.zip` 再发，微信里要按「文件」发送
3. 新电脑打开序集：点 **备份 → ⬆ 导入备份（追加）**，选中这个文件（压缩过就先解压）
4. 确认后，备份里的文件夹、文件夹层级、文件夹收藏、分组、图片原图、名称、备注、完成状态、图片收藏都会追加到当前数据

> 新版 `.jsonl` 是**流式读写**：一张一张导出、一张一张导入，不会把所有图片拼成一个巨大的 JSON，所以几百 MB 的数据也不会白屏。
> 导入是**追加**，不会覆盖或删除当前电脑上的已有数据；同名文件夹会自动加「导入」后缀。
> 旧版 `.json` 备份仍然可以导入；「导出旧格式 .json」只适合小数据（约 80 MB 以内），数据大时会提示改用 `.jsonl`。
> 备份文件包含图片原图，所以可能比较大，属正常现象。导出或导入过程中请不要关闭序集。
> 分享用的 PDF / ZIP / 长图只包含当前分组，**不包含文件夹结构**，不能当整库备份用。

## 数据存在哪里

- 数据保存在**当前电脑的本地数据库**（IndexedDB）里，不会上传到任何服务器。文件夹层级、文件夹收藏、分组、完成打勾状态也会一起保存。
- 换浏览器、换电脑、清理浏览器数据（“清除浏览数据”）都会导致内容丢失。
- **重要内容请定期点「备份 → 导出全部数据（.jsonl 推荐）」**，把 `.jsonl` 文件另存到安全的位置。

## 常见问题

**Q：点了「复制图文」没反应？**
A：确认页面处于焦点状态（先点一下页面空白处），并允许浏览器使用剪贴板。如果仍失败，改用「保存长图」，再在微信里发送文件。

**Q：图片显示不出来？**
A：HEIC（iPhone 原生格式）等个别格式浏览器无法解码，建议先转成 JPG/PNG。

**Q：换电脑后数据没了？**
A：数据只在本机。换电脑前先在旧电脑点「备份 → 导出全部数据（.jsonl 推荐）」，到新电脑用「备份 → 导入备份（追加）」导入；不要把 `index.html` 发给别人当作数据。

**Q：导入备份后原来的数据呢？**
A：原来的数据会保留。导入是追加式的，会把备份里的文件夹、分组和图片加到当前数据中，不会覆盖或删除已有内容；同名文件夹会自动加「导入」后缀。

**Q：能多人同时用吗？**
A：不能。它是单机工具，没有服务器和账号系统。

**Q：手机上能用吗？**
A：可以打开，但手机浏览器对本地文件 + 剪贴板的支持有限，推荐在电脑上使用。

## 技术说明

- 单文件：`index.html`（HTML + CSS + 原生 JavaScript，无任何第三方依赖、无 CDN）
- 存储：IndexedDB（图片以 Blob 存储）
- 备份：流式 `.jsonl`（一行一个文件夹/分组/图片，图片以 base64 内嵌），边读边写，导入时追加到现有数据（包含文件夹层级 / 文件夹收藏 / 分组 / 完成状态 / 图片收藏，不覆盖已有内容）；同时兼容旧版单文件 `.json` 备份
- 分享图：Canvas 2D 绘制，2 倍分辨率导出
- ZIP：内置极简 ZIP 打包实现（仅存储、不压缩，兼容 Windows 资源管理器/7-Zip/macOS）
- 剪贴板：异步 Clipboard API（`ClipboardItem`，PNG + 文本多类型）
- 完全离线：断网也能用
